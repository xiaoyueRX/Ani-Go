# Ani-Go 目录结构说明

这份文档是给 AI 助手（包括本喵）查阅用的，为了防止我们在乱七八糟的目录里迷路喵！

## 🌟 核心根目录
- `.cursorrules`：项目的核心“家规”（CGO 红线、GORM 防坑指南、UI 规范等）。**修改代码前必读**。
- `AGENTS.md` / `CLAUDE.md`：AI 助手的详细上下文、架构说明和 API 端点速查表。
- `README.md` / `README_EN.md`：中英双语的项目介绍。
- `main.go`：Go 后端的启动入口文件。
- `go.mod` / `go.sum`：Go 依赖管理。
- `docker-compose.yml` / `Dockerfile`：容器化部署配置。
- `ani-go.db`：本地 SQLite 数据库文件（包含用户数据和状态，**不可随意删除**）。

## ⚙️ 后端目录 (`internal/`)
这是 Ani-Go 的核心逻辑存放地，采用六边形架构：
- `internal/core/`：定义了所有的核心接口（如 `Source`, `Downloader`, `EventBus`）。**修改这里会影响全局，需谨慎！**
- `internal/api/`：HTTP 服务相关，包含路由注册 (`server.go`) 和接口逻辑 (`handlers.go`)。
- `internal/config/`：配置加载逻辑。
- `internal/database/`：GORM 数据库模型和迁移逻辑。
- `internal/source/`：各种数据源的爬虫实现（`mikan.go`, `yucwiki.go`, `multi.go`）。
- `internal/notifier/`：消息推送逻辑（微信、TG 等 16 个平台）。
- `internal/ai/`：统一封装的 AI 协议客户端（OpenAI/Anthropic/Gemini/Ollama）。

## 🎨 前端目录 (`web/`)
采用 Vue 3 + Vite + Tailwind v4 + DaisyUI v5 构建的纯前端：
- `web/src/`：Vue 源码目录。
  - `web/src/views/`：各个页面组件（设置页、订阅页等）。
  - `web/src/components/`：通用 UI 组件。
- `web/package.json`：前端依赖配置。
- *注意：开发时需在 `web/` 目录下运行 `npm run dev`；部署前需运行 `npm run build`，编译产物会被 `//go:embed` 嵌入后端。*

## 📁 辅助目录
- `docs/`：存放开发计划、交接文档和本文档。
- `scripts/`：存放自动化脚本（比如给 Hermes 注入架构神识的 `extract_semantics.py`）。
- `.github/`：GitHub Actions 的 CI/CD 工作流配置。
- `.gitnexus/`：GitNexus 的代码图谱索引数据（提供给 AI 进行爆炸半径分析）。
- `data/`：运行时生成的数据（如 JWT 密钥 `.jwt_secret`）。
