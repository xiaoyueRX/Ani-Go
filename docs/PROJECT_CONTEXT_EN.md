# Project background

[简体中文](PROJECT_CONTEXT.md)

Ani-Go grew out of two needs on a home NAS: follow new releases and fill missing episodes when an RSS feed has limited history. It connects existing downloaders and media servers through subscriptions, background tasks and file organization. Early deployments used fnOS. Containers and standalone binaries also support other NAS installations and hosts.

Hard linking serves users who keep seeding. The downloader retains its original path while the library gets names a media server can recognize. Separate subscription, episode and download records track tasks through organization. [Architecture](01_ARCHITECTURE_EN.md) · [Storage and deployment](05_DEPLOYMENT_EN.md)

The original handoff covered development through v0.6.0 and included machine-specific details and historical test results. For current configuration and release information, see the [quick start](../README_EN.md), [milestones](DEVELOPMENT_PLAN_EN.md) and [release history](../CHANGELOG.md).
