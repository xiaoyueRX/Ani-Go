# 项目背景

[English](PROJECT_CONTEXT_EN.md)

Ani-Go 起于家庭 NAS 上的两个需求：追到订阅源新发布的剧集，并在 RSS 历史记录有限时补齐缺集。它复用已有下载器和媒体服务器，把订阅、后台任务和文件整理连在一起。早期部署使用 fnOS；本项目也提供适用于其他 NAS 和独立主机的容器与二进制。

硬链接设计源于做种场景：下载器保留原路径，媒体库使用适合播放器识别的文件名。独立放置的订阅、剧集和下载记录帮助追踪任务与入库结果。[架构](01_ARCHITECTURE.md) · [存储部署](05_DEPLOYMENT.md)

原交接记录截至 v0.6.0，包含特定开发机的硬件、地址和一次性测试结果。当前配置入口和发布状态请参阅 [快速开始](../README.md)、[开发里程碑](DEVELOPMENT_PLAN.md) 和 [发行记录](../CHANGELOG.md)。
